# Automotive Sales BI Dashboard 📊

A Business Intelligence dashboard analysing automotive sales data 
using SQL and Python.

## What it does
- Stores sales data in a SQL database (SQLite)
- Runs BI queries to extract KPIs by model, region and month
- Visualises results in a clean 4-panel dashboard

## Key Insights
- Revenue breakdown by car model and region
- Monthly revenue trend analysis
- Customer financing rate analysis

## Tech Stack
- Python
- SQLite & SQL
- Pandas
- Matplotlib
